# Página web personal — Hellen

Repositorio **privado**. No está publicado como sitio web: los archivos se abren localmente.

## Cómo verlo

Abre `index.html` con doble clic (preferiblemente en **Google Chrome**).

> El audio y el micrófono de la práctica de inglés usan la Web Speech API,
> que funciona en Chrome. En Safari el audio puede fallar.

## Contenido

```
index.html                          Portada con los enlaces
practica-ingles/index.html          App interactiva de inglés (5 días, audio + quizzes)
descargas/guia-estudio-ingles.docx  Guía de estudio en Word
```

## Notas

- El progreso de los quizzes se guarda en `localStorage` del navegador,
  así que no se sube al repositorio ni se comparte entre dispositivos.
- Todo el contenido es estático: no hay dependencias ni build.
