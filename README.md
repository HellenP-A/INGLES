# INGLES

Repositorio **privado** con mi material de práctica de inglés.

## Contenido

```
index.html                       App interactiva: 5 días de gramática, audio y quizzes
guia-estudio-ingles-hellen.docx  La misma materia en Word, para leer o imprimir
```

## Cómo usarlo

Abre `index.html` con doble clic, preferiblemente en **Google Chrome**.

> El audio (🔊) y el micrófono (🎤) usan la Web Speech API del navegador.
> Funcionan en Chrome; en Safari el audio puede fallar.

## Notas

- El progreso de los quizzes se guarda en `localStorage` del navegador,
  así que no se sube al repositorio ni se comparte entre dispositivos.
- Todo es estático: no hay dependencias ni proceso de build.
- El repo es privado y el sitio no está publicado.
